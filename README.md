# Video Uniqualizer

`new.py` делает из одного видео N уникальных копий через FFmpeg.
Промпт, по которому он написан, лежит в [`PROMPT.md`](PROMPT.md).

## Структура папок

```
C:\Unic\15.09(CLAUDE)\
├── new.py
├── input_videos\    <- исходные видео
└── output_videos\   <- готовые копии
```

Без аргументов скрипт берёт все видео из `input_videos` и сохраняет результат в `output_videos`
с тем же именем: `IMG_0205.MOV` -> `IMG_0205.mp4` (при нескольких копиях `IMG_0205_2.mp4`, ...)
(обе папки ищутся рядом с `new.py`, откуда бы его ни запустили). В Windows можно запускать двойным кликом.

## Настройки

Все параметры лежат в начале `new.py`, в блоке **НАСТРОЙКИ**. У каждого есть комментарий:
какое значение ставить и что получится. Основное:

- `COPIES` — сколько копий делать из каждого видео.
- `FILTERS` — сила каждого фильтра: зеркало (HFLIP), масштаб, поворот, цвет, шум, резкость,
  виньетка, скорость, срез кадров, аудио. Значение `0` выключает фильтр.
- `ENCODER` — `"cpu"` (Ryzen, все функции) или `"amd"` (Radeon R7 370, быстрее, без CQM/AQ).
- `CRF` и `PRESET` — качество и скорость кодирования.

Вертикальные видео с телефона и HDR с iPhone обрабатываются корректно.

## Что меняется

| Параметр | Как |
|---|---|
| Визуал (pHash) | HFLIP (по умолчанию включён), микро-кроп, поворот, eq/hue, шум, unsharp, виньетка, pHash измеряется, `--min-phash` усиливает изменения до порога |
| MD5 / SHA-256 | перекодирование, случайные параметры энкодера, новые метаданные, удаление SEI |
| Lanczos micro-scaling | `scale=...:flags=lanczos+accurate_rnd+full_chroma_int` на 1–7 % + кроп со сдвигом |
| Custom AQ / CQM | случайные `aq-mode`/`aq-strength` + своя матрица квантования (`cqmfile`, только x264) |
| Незаметные | размытый фон по краям (blur_border), цветовая температура, лёгкая дисторсия линзы, дрейф камеры, выброс кадров, шумоподавление перед своим зерном, тихий розовый шум в аудио, ширина стерео |
| Движущиеся слои | пыль, световой блик (light leak), тепловое марево (heat haze) |
| Дополнительно | темп ±1–3.5 %, срез кадров, GOP/B-кадры/ref/me/subme/deblock/psy-rd, CRF, аудио: питч, громкость, EQ, high-pass, sample rate, битрейт |

## Установка

```bash
# нужен ffmpeg с libx264 (и libx265 для --codec h265)
pip install numpy   # для подсчёта pHash
```

## Примеры

```bash
python new.py                                   # input_videos -> output_videos, по 1 копии
python new.py -n 5 --intensity high --report report.json
python new.py -n 3 --min-phash 10 --seed 42
python new.py --codec h265 --format mkv
python new.py input_videos/clip.mp4 --dry-run   # только показать команду ffmpeg
```

Все случайные параметры берутся из `--seed` и сохраняются в JSON-отчёт.

## Надёжность

Видео и звук кодируются отдельными процессами и склеиваются без перекодирования. Сторож следит
за прогрессом: если ffmpeg `STALL_TIMEOUT` секунд не выдаёт новых кадров, процесс останавливается
и запускается более простой режим («безопасный», затем «минимальный»). Готовый файл
появляется в `output_videos` только после проверки длительности.
