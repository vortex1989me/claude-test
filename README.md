# Video Uniqualizer — `new.py`

HFLIP + зум + поворот + **OpenCV Mesh Warp**. Вся геометрия собрана в одну карту `cv2.remap`,
поэтому кадр интерполируется один раз (Lanczos). Звук копируется без изменений.

```
C:\Unic\15.09(CLAUDE)\
├── new.py
├── input_videos\    <- исходные видео
└── output_videos\   <- готовые копии (IMG_0205.MOV -> IMG_0205.mp4)
```

## Установка и запуск

```bash
pip install opencv-python numpy      # один раз; ещё нужен ffmpeg в PATH
python new.py                        # или двойной клик по new.py
```

Все настройки и допустимые максимумы описаны в начале `new.py`, в блоке **НАСТРОЙКИ**.

## Как устроено

`ffmpeg` (декодер) -> сырые кадры -> OpenCV `remap` -> `ffmpeg` (x264). Стадии связаны очередями.
Если какая-то стадия `STALL_TIMEOUT` секунд не двигается, всё останавливается с ошибкой, а не висит.
Файл появляется в `output_videos` только после проверки длительности.

Полная версия со всеми фильтрами (цвет, шум, рамка, пыль, блик, марево, аудио и т. д.)
сохранена в истории git: коммит `7db805f`.
